# Workout Roulette

Random HIIT workouts and runner-focused stretching routines with a guided timer, stretch diagrams, an editable exercise library and a monthly session log.

Live at **https://workouts.ciarandevine.uk** — open it in Chrome and choose **Install app**.

- `index.html` — the whole app
- `cloud.js` — shared sign-in and sync with the `ciaran-apps` Firebase project (data at `users/<uid>/workouts/`)
- `sw.js`, `manifest.json`, icons — make it installable and usable offline
- `CNAME` — the custom address for GitHub Pages

Signed out, everything is saved in the browser only. Use **Log → Backup → Export** to keep a copy.
